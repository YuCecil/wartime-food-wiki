# 需求訪談：先討論、後生成

日期：2026-11-17
做法：建檔前，AI（Claude Code）先訪談使用者，**一次問一題**，共 10 題（題目參考課堂列出的「AI 至少該問到」：讀者、資料類型、出處粒度、矛盾處理、一次一篇或批次、之後要產出什麼、檢查什麼）。問完整理成需求摘要，使用者確認後才寫 AGENTS.md、建資料夾與工具。

背景：這個 wiki 延續我上一週做的「戰時餐桌」（戰時臺灣 1937–1949 的糧食與日常生活，30 份資料、9 個故事）。這次訪談的重點是：這個 wiki 要怎麼支援「教學 HTML 簡報」。

| # | AI 問 | 我的回答 | 寫進規則的哪裡 |
|---|---|---|---|

| 2 | 教什麼範圍？ | 先選了「總覽」，確認摘要時改成**一個故事一份簡報** | 第 1、6 節 |

## 確認需求摘要時，我另外做的決定

- **一個故事一份簡報，可以一直做下去**：不做總覽，流程做成 `/story-slides <故事id>` 指令重複使用。
- **當成新專案整理**：上週的檔案很多是為上週作業做的。只搬必要的內容（資料卡、故事、名詞、原文），拿掉網站程式、時間軸、地圖、吉祥物等。
- **Wiki 直接在 GitHub 上看**：連結改成一般 Markdown 連結；網頁只放簡報。
- **主規則改放 AGENTS.md**：上週的 CLAUDE.md 有 15,323 字元，超過課堂提到的 Antigravity 規則檔上限 12,000 字元。改成 AGENTS.md 為主（5,756 字元）、CLAUDE.md 只寫 `@AGENTS.md`，細節拆到 `.agents/workflows/`。
- **AI 審查開新對話**：由 Claude Code 另派一個子代理，只給逐頁稿和證據卡。
- **發布**：開新的 GitHub 儲存庫，上週交的網站不動。
